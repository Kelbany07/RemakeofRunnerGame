# RemakeofRunnerGame
(I lose my old progress, so I made a new repository)
The Repository for my Endless Runner Game. Planning to create a side-scrolling endless running game. In the upcoming weeks, this project will be known as "Puppy Pursuit," a side-scrolling, endless runner game. The desired goal will be to control your dog, collect bones, and use the up arrow key to jump. Since the game is endless, the goal of the player is to simply survive and try to collect as many bones as they can. This game will consist of bottomless pits the player will need to avoid, along with cat-like enemies the player can jump over or shoot to avoid.

This project will feature sprites mostly created by me. Any sprites from outside sources will be properly credited when the time comes. I plan to incorporate a feature where the player can "shoot" to destroy the cat-like enemies. This endless runner will consist of a randomly generated layout that increases in difficulty/speed overtime. Asides from pits the player will have to jump over, I also want to add objects the player can jump over, like boxes or bottles.
